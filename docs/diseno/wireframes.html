10

Flujo de compra

UC04 → UC16 — recorrido completo

De agregar al carrito hasta el correo de confirmación. Los tramos grises son procesos automáticos: no los inicia ninguna persona.

UC04 Arma el carrito Sin sesión. No reserva stock.
UC28 · sistema Aplica ofertas Una sola por ítem, según vigencia.
UC06 / UC07 Ingresa Local o Google. Fusiona el carrito.
UC10 Confirma Dirección, revalidación y pedido pendiente.
UC29 · sistema Valida kits Stock de todos los componentes.
UC11 Paga Mercado Pago. Webhook validado.
UC27 · sistema Descuenta stock Solo si el pago fue aprobado. Transacción única.
UC16 · sistema Notifica Comprobante por correo y en el historial.

El punto de no retornoEl stock se descuenta recién con el pago aprobado, nunca antes. Si una venta simultánea deja un ítem corto, la transacción se revierte entera y el pedido pasa a revisión manual. UC27 RNF16

Webhook idempotenteMercado Pago puede notificar el mismo pago más de una vez. Se procesa una sola. Una notificación que no valida se descarta sin tocar el pedido. RF33

Pago rechazado o pendienteEl pedido queda en ese estado, no se descuenta stock y se ofrece reintentar. RF32
